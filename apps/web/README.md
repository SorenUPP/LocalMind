The LocalMind web app is the browser interface for querying the local sales dataset.

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The API is expected at `http://localhost:8000` by default; override it with `NEXT_PUBLIC_API_URL` when needed.

Run `npm run lint` before committing changes.
